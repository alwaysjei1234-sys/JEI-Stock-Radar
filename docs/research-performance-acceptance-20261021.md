# JEI 研究與績效驗收規格（2026-10-21）

本文件定義下一階段的驗收標準；不代表下列功能已上線。

## 研究卡片必填欄位
- 股票代碼、名稱、產業、資料來源、資料時間及新鮮度
- 營收年增率、近四季 EPS、毛利率、營益率、自由現金流、負債情況；缺值顯示「待驗證」，不得補零
- 主要產品、客戶集中風險、成長動能；區分已公告事實／分析推論／市場傳聞
- 同業至少兩家：成長、獲利、估值與競爭優勢；資料不足時不給比較結論
- 量價、法人、主流題材與市場環境；記錄每項訊號日期
- 續強、區間震盪、跌破關鍵位三情境：觸發條件、行動、失效條件
- 不構成保證收益或自動下單指令

## 模擬績效（現股與當沖分帳）
- 推薦產生時寫入不可覆寫的 event：時間、代碼、策略版本、推薦價與行情時間、理由、停損及目標
- 以交易日計算 3/7/15/30/60/90 日績效，收盤價採經驗證資料；除權息與交易成本需明確處理
- 尚未到期標示「觀察中」，缺行情標示「無法計算」，不可用 0% 代替
- 同時統計全部訊號（含失敗及下架標的）的勝率、平均損益、盈虧比、最大回撤及對照基準
- 嚴禁回填當時未知的資訊；策略版本改動後分組計算，另做樣本外驗證

## 大盤檢查
- 台股大盤與量能、外資及投信、期貨、重要族群、支撐壓力、重大事件
- 各訊號附資料時間，輸出偏多／震盪／偏空及原因；資料不足則顯示「訊號不足」

## 80% 驗收門檻
採 10 項端到端測試，至少 8 項通過且第 1、2、3 項必須通過：
1. 官方行情取得與時戳
2. 休市及盤後仍可顯示最近有效資料
3. 缺值與過期資料不會被當成最新訊號
4. 基本面及來源追溯
5. 同業比較
6. 三情境策略
7. 現股模擬事件留存
8. 3/7/15/30/60/90 日績效
9. 大盤風險與 LINE 訊息一致性
10. Android 啟動、遠端更新與手機 UI

狀態：規格建立；實作與驗收仍須逐項確認。
