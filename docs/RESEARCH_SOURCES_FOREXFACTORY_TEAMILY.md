# Forex Factory 與 Teamily AI 來源評估

檢視日期：2026-11-03

本文件記錄新增研究來源的用途、限制與接入條件。這些來源只能補充 JEI 的研究判斷，不能取代官方行情、官方經濟數據或 JEI 自己的模擬績效驗證。

## Forex Factory

官方首頁列有經濟日曆、新聞、主要外匯市場等區塊。經濟日曆可用來整理事件時間、幣別、影響等級，以及實際值、預期值、前值。

### 建議用途

- 盤前／盤後提醒 CPI、非農、FOMC、ISM 等可能影響美股與台股風險偏好的事件。
- 將事件與美元、美債殖利率、VIX、費半、台積電 ADR 等跨市場資訊一起判讀。
- 事件公布後，記錄實際值相對預期值的差異，作為後續盤勢解釋線索。

### 資料規則

- Forex Factory 作為事件索引與新聞線索來源；公布時間、數值和政策內容應再核對美國政府、央行或統計機關等官方來源。
- 不把論壇留言、交易者觀點或網站新聞摘要當作已驗證事實。
- 每筆資料標示來源與抓取時間；缺值、過期或無法核對時明確標示，不推估填補。
- 此來源不提供 JEI 的台股官方成交價依據，也不直接產生買賣訊號。

官方來源：[Forex Factory](https://www.forexfactory.com/)

## Teamily AI

Teamily 官方更新紀錄提到 Agent APIs，包含 OpenAI 相容模式與 MCP／REST 分享介面。公開資訊尚未提供足以在 JEI 直接設定的端點、認證規格、方案費用及用量限制。

### 建議用途

若帳號內 API 可用、費用符合 JEI 的免費優先原則，可作為額外的研究 Agent，協助整理總經、產業趨勢和公開新聞，供 JEI 現有多 AI 會診交叉比較。輸出須保留模型／來源名稱、時間及原始引用，並與官方數據分開。

### 接入門檻

- 先確認 Agent API 的端點、認證方式、模型／Agent 識別方式、速率限制與計費方式。
- 由服務端安全保存 API Key；不得放入公開程式碼、前端設定、公開 JSON 或 GitHub。
- 未確認費用前不呼叫付費服務；不得自動切換到會產生費用的模型。
- 初期只傳送必要的公開研究問題，不傳送個人持股、成本、股數或其他私人資料。
- 完成設定後須驗證成功／失敗狀態、逾時、額度耗盡及費用提示；任何失敗不得偽裝成模型已提供意見。

官方參考：[Teamily AI](https://teamily.ai/)、[Teamily AI Changelog](https://teamily.ai/changelog)、[隱私政策](https://teamily.ai/about/privacy-policy)、[服務條款](https://teamily.ai/about/terms-of-service)

## JEI 採用原則

1. 官方行情與官方公布資料仍為事實基準；第三方網站和 AI 只提供線索或解讀。
2. 新增來源必須顯示來源、時間、資料新鮮度及驗證狀態。
3. AI 觀點不得計入歷史勝率或模擬績效；績效只能由可重現的選股紀錄和後續行情計算。
4. 在 API 規格、費用和帳號權限確認前，Teamily 僅列為候選整合，不算已接通功能。
