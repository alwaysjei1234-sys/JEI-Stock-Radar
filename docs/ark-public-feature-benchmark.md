# 方舟運算公開功能研究 → JEI 自主設計方案

來源：Google Play com.galaxy.ark 與 App Store id6751102676 公開介紹及更新紀錄；僅參考公開可見功能，不聲稱取得其私有程式碼、演算法、API 或資料庫。

## 功能對照與優先級
P0 市場風控：大盤/市場廣度/法人/波動/資料時間 → 風險級別與理由；缺資料時禁止宣稱低風險。
P0 位階：採公開可驗證價格分位數、獲利成長與估值區間；標記低估候選/中性/過熱，絕不稱其為方舟原始公式。
P0 部位計算：可用資金、單檔風險上限、停損距離、最小交易單位與流動性；若停損距離無效不計算股數。
P1 多策略篩選：基本面、產業成長、籌碼、量價、流動性五個獨立分數，保留各分項與來源。
P1 持股配置：市值、成本、損益、產業集中度、台美股及匯率日期；私人持股不寫入公開 remote feed。
P0 策略績效：保存當時推薦快照，3/7/15/30/60/90交易日追蹤，與同期基準比較，避免倖存者偏誤。

## JEI 差異化
額外保留主攻、下一棒、妖股、未來妖股分類；盤前/盤中/盤後與美股時段資料新鮮度；LINE 警示；現股與當沖模擬帳本分離。

## 驗收
逐項檢查輸入資料來源、演算法輸出、缺值行為、畫面呈現、手機互動、績效事件持久化及回歸測試。
