# 2026-11-02 資料可靠性修正

## 財報端點季度切換

官方一般產業端點僅回傳部分新季度公司時，保留前次官方快照中仍在市場清單內公司的完整財報紀錄。保留原季度、出表日與首次快照時間；畫面標示「本次端點缺漏，保留前次季度」。不混合不同季度、不更新舊資料日期、不帶入私人欄位。新季度即使只有部分欄位也不以舊季度補值。這只恢復資料更新流程，不表示已取得全部最新季報。

## 盤中 MIS

股票與加權指數均檢查交易時間；只讓最近十分鐘內成交計入有效盤中覆蓋，容許最多一分鐘的抓取時鐘差。過舊、未來、非有限價格與重複股票不得增加覆蓋率。不以買賣掛單、昨收替代成交。十分鐘門檻會使較久沒有成交的股票不計入有效覆蓋，這是刻意保守的資料規則。
