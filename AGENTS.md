# JEI Stock Radar coding-agent instructions

Read [docs/JEI_AGENTIC_QA_GATES.md](docs/JEI_AGENTIC_QA_GATES.md) before modifying the repository. Use isolated branches, reproducible failing tests, then narrow fixes and full regression evidence. This file is process guidance, not permission to run third-party hooks or install dependencies.

Never claim real data verification, completed Windows/mobile release or real trading integration without artifact evidence. Do not expose credentials, private holdings or the formal finance ledger. When tests are blocked, record the exact blocker and keep the PR in Draft.

## Cross-project AI knowledge handoff

Before taking over work, read [JEI shared AI knowledge and handoff](docs/JEI_SHARED_AI_KNOWLEDGE.md). Preserve the project-specific QA gates above. Keep private project information out of the shared public knowledge base; hand off only transferable techniques.
